# Magma - Web3 Real Estate Platform  🏢✨

A stunning, fully responsive frontend clone of the Magma Web3 real estate platform landing page. This project replicates the original site's visually immersive experience, showcasing how physical buildings are certified into unique Digital Twin Tokens (DTT) using advanced scroll-driven animations and a crisp, modern UI.

🌐 **Live Demo:** [View the Live Project](https://nikhilgoswami9995.github.io/Magma-Web3-Real-Estate-Platform/)

---

## 🚀 Features

* **Immersive Scroll Animations:** Utilizing frame-by-frame canvas rendering to deliver seamless, high-performance 3D visual transitions as the user scrolls.
* **Modern Web3 UI/UX:** Clean typography, glassmorphism elements, and glowing gradients that replicate the futuristic aesthetic of decentralized real estate.
* **Fully Responsive:** Optimized for crisp layouts across desktops, tablets, and mobile screens.
* **Text & Reveal Effects:** Smooth scroll-triggered text animations that elevate the storytelling flow.

---

## 🛠️ Tech Stack

* **HTML5 & CSS3:** For semantic structure, custom layouts, and responsive styling.
* **JavaScript (ES6+):** Core logic managing the dynamic canvas rendering, image sequence preloading, and user interactions.
* **GSAP (GreenSock Animation Platform) & ScrollTrigger:** Powering the heavy lifting behind the ultra-smooth, scroll-bound animation frame sequences.

## 🔧 Getting Started & Local Setup

To run this project locally on your machine, follow these simple steps:

1. **Clone the Repository:**
```bash
git clone [https://github.com/nikhilgoswami9995/Magma-Web3-Real-Estate-Platform.git](https://github.com/nikhilgoswami9995/Magma-Web3-Real-Estate-Platform.git)

```


2. **Navigate to the Directory:**
```bash
cd Magma-Web3-Real-Estate-Platform

```


3. **Run the Project:**
* Simply double-click the `index.html` file to open it in any modern browser.
* *Alternative (Recommended):* Use a local development server like the **Live Server** extension in VS Code to ensure smooth loading of your assets and scripts.
